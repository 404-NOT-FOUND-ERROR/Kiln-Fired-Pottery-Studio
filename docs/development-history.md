## 完整制作流程

从一个开口的小罐泥坯开始：**选择轮廓起点 → 湿泥塑形 → 自动半干修足、干燥与素烧 → 彩绘 / 施釉 → 釉烧与冷却 → 拍照 / 观察 → 收藏到作品列**。六种起点包含小罐、茶碗、梅瓶、玉壶春、葫芦瓶和斗笠碗，均可继续自由塑形。

- **塑形**：保留整圈推拉、拉高收窄与抚平，新增手捏局部推拉、指腹压痕及不对称手捏罐起点。局部塑形只改变接触的一侧，口沿可以起伏，内壁一起变化并保持厚度。支持撤销、重置和缓转。
- **起点与塑形分开**：器形卡片只出现在起点页。进入塑形后，重新选起点需要明确确认清除当前塑形；取消会保留原件。
- **自动准备**：湿泥、皮革硬度、全干与素烧坯分别呈现不同的颜色、粗糙度和反光。连续靠近、翻转、绕足与回正，用真实网格展示一圈削底；轨迹随器物翻转，方向与实际削底一致，不显示泥屑。干燥与素烧合为一个短段落，整段约 8.4 秒。匀速时轮、正在制作的状态与轮换小贴士表现时间流逝，完成后淡入装饰；可取消并返回塑形。
- **装饰**：默认使用窑变釉，可一键铺底、换色叠刷。纹样彩绘使用独立图层，默认罩透明釉并保留落笔位置与颜色。软刷具有透色、柔边和细刷毛间隙，重复经过逐渐积厚；按笔迹距离取样，支持压感笔。19 种颜色加自定义颜色，刷釉、转台环带、浸釉、淋釉、擦除、叶纹、小花和撤销均保留。
- **烧后表面**：流彩窑变、柔雾晶花、铁锈星斑、冰裂开片四个效果釉使用不同的颜色、粗糙度与凹凸规则，选择时显示由同一规则生成的小样。流彩随厚度形成流动与聚色；晶花偏哑光，铁斑与开片各有不同的细部。底足保持无釉，冷却对照保留。
- **绘制工作台**：左侧调节笔刷与釉量，底部放绘制工具与色盘，右侧选择材料、效果与烧成；选项讲解随点击出现。桌面与手机尺寸均检查常用控件可直接点击，无需滚动控制栏。
- **烧成**：时轮与温度图共用匀速时间轴，高温段绘制成较长的平台。整段约 8.6 秒，时间分配为升温 18%、高温阶段 58%、冷却 18%、收尾 6%；这是叙事节奏，不能当作真实窑炉程序。制作与烧制都自动完成，没有跳过或暂停按钮；支持系统减少动态效果设置。
- **烧成后拍照，再收藏**：烧成后直接进入拍照，默认藏品背景，也可选纯色、窗边或色场。没有柜体、开门或架位动画。拍照、观察和器物查看共用暖色玻璃侧栏与底部控件。无需先收藏即可观察或下载；收藏保留当前背景与机位，改名更新同一件作品。收藏列只展示实际器形与釉面的透明缩略图；旧缩略图也按原始存档重新渲染。打开收藏后先在中性背景查看器物，再观察或重新拍照。

塑形、装饰、展示、保存使用同一件器物的轮廓、局部形变与稳定 UV。保存包含原始彩绘层、颜色釉层、烧后颜色、覆盖、粗糙度和凹凸贴图以及本件作品的随机种子；刷新取回保持同一结果。旧版 IndexedDB 作品仍可读取。

## 模型边界

塑形是有厚度与形变约束的轮廓及局部表面编辑，并非湿泥物理模拟。釉色、流动、表面和烧成组合是艺术化示意，不是釉料配方或烧成预测。纹样彩绘位置与颜色不变，窑变釉按相对厚度和预设产生流动、矿物色晕或表面结构；缓冷的晶花、聚色和铁斑变化只属于当前效果规则，不能推广到所有釉料。真实结果取决于泥料、釉料、气氛及温度曲线。

展示场景使用 Blender 底图和实时器物，支持全貌、特写与俯视机位，以及围绕器物的轻微视差（水平约 ±2°、垂直约 ±1.3°）。底图按台面深度连续重投影，焦点保持在器物上；底图覆盖有限，不能自由绕房间行走。纯色拍照背景可自由环绕。可切换为转动器物，或按住 Shift 拖动；触屏支持单指拖动、双指缩放，方向键微调机位、Home 复位。收藏保存拍照机位和角度。示例作品使用烘焙釉色，自制作品保留用户自己的器形与装饰。

## 单 HTML 交付

制作界面采用“留白光室”：与概念图对应的二维光影底图、暖白毛玻璃、浮动塑形工具和统一的操作面板。泥面使用缓存的程序纹理呈现细密拉坯痕、颗粒与湿润度变化，干燥和素烧逐步转为哑光浅色；保留烧后釉层各自的材质效果。二维底图围绕器物的屏幕落点与取景缩放联动，界面保持固定；制作阶段没有加载房间模型，三种摄影场景仍按需加载。

塑形页按参考图的布局和文案实现：左侧调整笔刷大小，右侧显示器物尺寸和局部力度，底部选择推拉、手捏、压痕、抚平和拉高；撤销、复位、旋转和缩放保持可见。转台缓转、重新起坯和视角复位放入右侧“···”菜单。桌面版已检查 1024×720、1280×720、1366×768、1600×900、1672×941 和 1920×1080 下主要文字与控件无需上下滚动，包含四种施釉方式和四种效果釉。运行 `node tests/reference-studio.cjs` 检查这一屏布局和底图缩放，运行 `npm run test:light` 可检查实际捏塑影响、撤销和五种屏幕宽度下的工具可用性。

运行 `npm run build:single` 生成 `dist/pottery-studio.html`，约 32 MB。脚本、CSS、模型、图片、HDR、烧制 Worker 与许可证都内嵌，可用 Edge 或 Chrome 直接双击打开，无需本地服务器和联网。制作、烧制、观察对照、三种拍照场景、收藏及图片下载均保留；文件大小来自原有高清图片和模型。

收藏仍存放在浏览器的 IndexedDB 中，不写入 HTML。网站版本的旧收藏不会自动转到本地文件，发送 HTML 也不会包含接收者的收藏。更换浏览器、来源或清除浏览器数据后，应使用之前下载的作品卡保留成片。古代器型资料的外部参考链接仍需联网。

收藏只属于当前浏览器、当前网站来源；清除网站数据、改变端口或换浏览器不会自动迁移。下载作品卡可保留成片，图片不包含可编辑的三维数据。

## 验证

`npm run test:profile` 验证轮廓、内外壁与 UV；`npm run test:making` 验证完整制作、四种施釉、撤销、底足、导出、上架、恢复和手机流程；`npm run test:layout` 验证制作区五种宽度与固定操作区。保留原有 `test`、`test:ui`、`test:museum`、`test:living`、`test:art`、`test:optics` 回归。自动化需要 Playwright 与浏览器，环境设置见 [QA.md](QA.md)。

`npm run test:glaze` 验证四种效果的输出区别、稳定彩绘、底足与随机种子复现；`npm run test:reactive` 用实际鼠标检查局部手捏、透色叠刷、四种实际烧成、保存取回及彩绘颜色保留。随后运行 `node tests/firing-review.cjs`，可从该真实记录重新生成上述材质对比图。

`npm run test:workflow` 检查新的步骤层级、自动过场、浮动工具、出窑与直接收藏的先后顺序、推荐入口、旧作品和示例、手机布局。`node tests/workflow-safety.cjs` 检查确认重新起坯及收藏被禁用时的作品下载退路。
