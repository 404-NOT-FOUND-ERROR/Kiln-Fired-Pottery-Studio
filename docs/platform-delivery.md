# 懂了鸭单 HTML 交付

上传文件：`platform/index.html`。无需 ZIP，也无需上传图片、模型或源码目录。

本地预览：启动 `node serve.cjs` 后打开 `http://127.0.0.1:4173/platform/index.html`，也可以直接双击 HTML。收藏保存在当前浏览器、当前地址下；文件预览和平台网址的收藏不会自动互通。

本版保留塑形、装饰、烧成、观察、三种拍照场景、收藏和作品卡预览/导出。适配只应用于平台版本，原来的 `dist/pottery-studio.html` 仍保留。

## 打包

```text
npm run build:single
npm run prepare:platform
npm run build:platform
```

第二步需要 Python、NumPy 和 Pillow。它从完整离线版本提取资源，生成 `qa-artifacts/platform-assets/`；第三步读取当前源码与这些资源，生成上传入口。构建会在入口超过 10,000,000 字节或残留相对资源路径时失败。

32 项图片、光照和网格资源采用 WebP、HDR 缩采样与紧凑网格存储。模型保留顶点、三角形和 UV 拓扑，按需在本地解码。资源总数据约从 21.92 MB 减至 5.12 MB；最终 HTML 约 9.22 MB。没有在线 CDN 或外链素材依赖。

为了保留用户指定的单 HTML 离线交付，本版仍内嵌模型资源；此处按用户要求优先于 Skill“不把模型编码进 HTML”的规则执行。各单项资源低于 1 MiB，但仍应关注低端设备内存。平台版本限制绘制像素与 DPR，后台暂停绘制，并为 WebGL 中断和不支持的浏览器提供状态提示。需要支持 WebGL2、Blob 模块和 DecompressionStream 的现代浏览器。

## 验证与边界

本机运行 Skill 的 Node/Python 静态审计和原版布局检查内核。检查 1440×810、1024×768、768×1024、390×753、352×447；另有触控手势、过场、作品卡、收藏与资源恢复检查，详见 `QA.md`。

小屏工具面板、色盘和窄屏塑形工具条有局部滚动；可展开面板。检查器会把滚动容器中尚未滚入的文字报告为遮挡，这些项另以滚动后的实际点击检查复核。

官方在线预览桥因传递完整 HTML 到外部页面而被自动审批拒绝，因此本次使用本地离线预览，没有上传作品。浏览器触控模拟不等于实体 iOS、Android 或微信 WebView 验证。
