# 制作流程与观察室细化

本轮：生图封面 → 六种器形起点 → 湿泥塑形 → 自动逐圈修足 → 连贯干燥、素烧、冷却 → 默认展开的绘制工作台 → 釉烧与出窑 → 直接收藏到作品列 → 三种拍摄场景或中性光照对照。

封面由内置 image_gen 生成，网页实际加载 118 KB 的 WebP。完整提示词与 PNG 原图位置记录在 [生成记录](../design-concepts/cover-20261007.json)。封面不创建 WebGL 上下文。

起点包含小罐、茶碗、梅瓶、玉壶春、葫芦瓶、斗笠碗；缩略轮廓由同一组模型半径数据绘制。传统器形仅作轮廓参考，不声明是具体文物复刻。梅瓶与玉壶春说明参照 [故宫梅瓶释义](https://www.dpm.org.cn/lemmas/239389.html)、[故宫玉壶春释义](https://www.dpm.org.cn/lemmas/241111.html)；葫芦瓶轮廓参照 [美国国家美术馆藏品](https://www.nga.gov/artworks/1730-vase-shape-double-gourd)。

湿泥采用程序生成的细颗粒、拉坯纹、粗糙度及色差；半干和干燥时连续改变颜色与反光。削底沿圆周逐步改变实际底部网格，完整一圈后提交圈足，不改变 UV；无需用户点击修底，不显示刮刀。干燥与素烧合并为一个连贯科普段落，仍依次进行，不把两种物理过程混为一谈。

绘制设置默认展开。桌面左工具、底部色盘、右效果与烧成；手机把设置分成两个紧凑区域放在模型下方。原有笔刷尺寸、釉量、四种施釉方式、彩绘与窑变釉分层、纹样、透明釉、撤销和相机操作继续使用原来的事件与数据。

新收藏直接保存并显示缩略图列，不创建三维作品架、架位或额外渲染器。既有记录仍可读取，旧的 slot 字段不参与呈现。作品使用 IndexedDB 保存器形、原始材料层及烧后颜色、粗糙度、釉厚与微表面贴图；存储失败时仍可观察和下载，不能虚报收藏成功。

观察室用同一模型、同一视角和中性光照：左右分区展示烧前／烧后，或本次／另一冷却预设。可拖动分界线或滑块，也保留三个单独观察状态及照片导出。两侧复用网格与渲染器，各自缓存材质，避免每帧重新配置所有釉面参数。

窑变仍是现象的艺术化示意，非真实釉料配方预测；泥料和烧成曲线未经物理标定。收藏保存在当前浏览器来源。尚未覆盖 iOS/Android 真机与长时间存储压力测试。
